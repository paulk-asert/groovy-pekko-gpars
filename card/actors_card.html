THE ACTOR SYSTEM
GROOVY 6 · THE WHOLE BOT ACTOR 
@ActiveObject
class HelloWorldBot {
    private final int max
    private int greetingCounter

    HelloWorldBot(int max) { this.max = max }

    @ActiveMethod(blocking = false)
    void greeted(String whom, HelloWorld from) {
        greetingCounter++
        println "Greeting $greetingCounter for $whom"
        if (greetingCounter < max)
            from.greet(whom, this)
    }
}
Groovy 6 actors are just annotated classes — no Behavior types, no receive builder, no message records, no locks.
