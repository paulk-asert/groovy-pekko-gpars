PEKKO · THE BOT, PROVED 
@Invariant({ max >= 1 && 0 <= greetingCounter
             && greetingCounter < max })
class HelloWorldBot extends AbstractBehavior<Greeted> {
    // … fields, @Requires constructor, createReceive …

    private Behavior<Greeted> onGreeted(Greeted message) {
        greetingCounter++
        context.log.info "Greeting $greetingCounter for $message.whom"
        if (greetingCounter == max) {
            return Behaviors.stopped()
        } else {
            message.from.tell(new Greet(message.whom, context.self))
            return this
        }
    }
}
THE COMPILER SAYS
INVARIANT · the weaker greetingCounter <= max
Cannot prove class invariant of onGreeted holds at method exit
    counterexample: greetingCounter = 1, max = 1
REPLY · a greeter that skips long names
onGreet may return without a reply on command.replyTo
    counterexample: command.whom = "ABCDEFGHIJKLMNOPQRSTUVWXYZ…"
DEADLOCK · a Groovy 6 actor, bounded BLOCK mailbox
Actor mailbox deadlock in 'knot': the send to 'worker'
(line 12) is the 3rd to a mailbox bounded at 1 with
Overflow.BLOCK … The handler cannot: it is waiting for
the receive on 'gate' (line 8), which this method sends
only at line 13, after the send that blocks. …
